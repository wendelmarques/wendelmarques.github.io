## Rodando localmente

Não há build step — é só clonar e servir como site estático:

```bash
git clone https://github.com/wendelmarques/wendelmarques.github.io.git
cd wendelmarques.github.io
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

> **Nota:** alguns embeds (como vídeos do YouTube) exigem que a página seja servida via `http(s)://` — abrir o `index.html` direto pelo sistema de arquivos (`file://`) pode causar erros de carregamento nesses embeds.
